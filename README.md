Flutter Weather App
Ứng dụng thời tiết được xây dựng bằng Flutter, tích hợp API từ OpenWeatherMap.
- Hiển thị thời tiết hiện tại (nhiệt độ, độ ẩm, gió, áp suất, tầm nhìn)
- Dự báo thời tiết 24 giờ tới
- Dự báo thời tiết 5 ngày
- Tìm kiếm thành phố
- Lưu lịch sử tìm kiếm
- Quản lý thành phố yêu thích (tối đa 5)
- Tự động lấy vị trí GPS
- Cache dữ liệu offline
- Giao diện thay đổi theo điều kiện thời tiết
- Pull-to-refresh
Thư viện sử dụng
- http
- provider
- geolocator
- geocoding
- shared_preferences
- intl
- flutter_dotenv
